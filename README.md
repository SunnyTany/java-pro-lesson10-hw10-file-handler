# File I/O Handler Application

Простое консольное Java-приложение для демонстрации работы с файловой системой (чтение и запись текстовых файлов) с использованием классического Java IO API.

## Функционал
- **Запись в файл**: Сохранение текстовой строки в файл в указанную директорию.
- **Чтение из файла**: Посимвольное чтение данных из файла с использованием `StringBuilder`.
- **Инкапсуляция логики**: Весь процесс формирования путей и работы с потоками вынесен в отдельный класс `FileHandler`.

## Структура проекта
- `app.Main` — точка входа, содержит логику взаимодействия с пользователем.
- `app.FileHandler` — сервис для работы с файловыми потоками (`FileWriter`, `FileReader`).

## Требования
- Java 8 или выше.
- Наличие папки `files/` в корневом каталоге проекта для корректной работы записи.

## Как запустить
1. Скомпилируйте файлы:
   ```bash
   javac app/*.java
   ```
2. Запустите приложение:
   ```bash
   java app.Main
   ```

## Пример вывода
```text
RESULT: Success.
FILE CONTENT: My very important information.
```
